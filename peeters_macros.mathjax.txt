Installation instructions for the plugin:

   Unzip the downloaded .zip archive to the /wp-content/plugins/ directory
   Activate the plugin through the ‘Plugins’ menu in WordPress.
   This uses the mathjax CDN(http://www.mathjax.org/docs/1.1/start.html#mathjax-cdn). Alternatively:
   Download the MathJax Javascript library (http://www.mathjax.org /download/)
   Place the Javascript library in the mathjax-latex directory (/wp-content/plugins/mathjax-latex/MathJax)
   You can configure the plugin to load MathJax from a different URL to the default. See the options page.
